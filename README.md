# Magic Archaeology

Magic is an art that's long gone, if it ever existed at all. Or at least that's what you thought, until you found some ancient relics which seem to be trying to teach you how to cast spells. Now if only you could understand exactly what they're saying...

Arcane Archaeology is a short puzzle game about interpreting cryptic clues to uncover the rules that govern spellcasting.
